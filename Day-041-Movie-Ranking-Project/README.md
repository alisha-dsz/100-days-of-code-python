# Day 41 - Movie Ranking Project

## 📖 Overview

The **Movie Ranking Project** is a simple HTML project created as part of the **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

The project is a basic webpage that displays my personal top 3 movies along with a short description of each movie.

Although this project is part of a Python learning journey, Day 41 introduces the basics of **HTML and web development**, including HTML structure, headings, paragraphs, and horizontal lines.

---

## 🎯 Objective

Create a simple movie ranking webpage that:

- Displays a main heading.
- Displays a subheading.
- Shows the top 3 favorite movies.
- Provides a short description for each movie.
- Uses basic HTML elements.
- Understands the basic structure of an HTML document.

## 📚 HTML Elements Used

### `<!doctype html>`

Tells the browser that the document is written using modern HTML.

### `<html>`

The root element of the HTML document.

### `<head>`

Contains information about the webpage that is not directly displayed on the page.

### `<title>`

Sets the title that appears in the browser tab.

```html
<title>Movie Ranking Project</title>
```

### `<body>`

Contains all the visible content of the webpage.

### `<h1>`

Used for the main heading of the webpage.

```html
<h1>Best Movies According to Alisha</h1>
```

### `<h2>`

Used for a secondary heading.

```html
<h2>My top 3 movies of all times.</h2>
```

### `<h3>`

Used for the movie names.

```html
<h3>Spirited Away</h3>
```

### `<p>`

Used to write descriptions or paragraphs.

```html
<p>This is my favorite anime. I love the beautiful pictures.</p>
```

### `<hr />`

Creates a horizontal line to separate sections of the webpage.

```html
<hr />
```

## 💻 Code Structure

The webpage follows this basic structure:

```text
HTML Document
      ↓
    <html>
      ↓
    <head>
      ↓
   Page Title
      ↓
    <body>
      ↓
   Main Heading
      ↓
  Subheading
      ↓
 Horizontal Line
      ↓
 Movie 1 + Description
      ↓
 Movie 2 + Description
      ↓
 Movie 3 + Description
```
