# Day 19 - Turtle Race

## 📖 Overview

The **Turtle Race** is a graphical Python game built using the `turtle` module. Players place a bet on the turtle they think will win the race. Six turtles, each with a unique color, race across the screen at random speeds until one reaches the finish line.

This project introduces event-driven programming, graphical user interfaces, and randomness while creating an interactive game.

---

## 🎯 Objective

Create a turtle racing game that:

* Displays multiple turtles with different colors.
* Allows the player to bet on a turtle.
* Randomly moves each turtle forward.
* Determines the winning turtle.
* Announces whether the player's bet was correct.

---

## 🎮 Gameplay

1. Enter the color of the turtle you think will win.
2. Watch the turtles race across the screen.
3. If your chosen turtle reaches the finish line first, you win the bet!
