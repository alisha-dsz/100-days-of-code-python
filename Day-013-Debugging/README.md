# Day 13 - Debugging

This folder contains the debugging exercises completed during **Day 13** of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

Unlike previous days, Day 13 focuses on improving debugging skills rather than building a standalone project.

---

## 📚 Topics Covered

- Identifying syntax errors
- Fixing logical errors
- Reading and understanding error messages
- Debugging Python functions
- Using `print()` statements to trace program execution
- Applying systematic debugging techniques

---

## 🛠 Exercises Included

### 1. Debugging Odd or Even
- Fixed a syntax error in the conditional statement.
- Verified correct identification of odd and even numbers.

### 2. Debugging Leap Year
- Corrected the leap year calculation by fixing the divisibility condition.
- Tested the program with different year values.

### 3. Debugging FizzBuzz
- Fixed the conditional logic using the correct order of `if` / `elif` statements.
- Corrected the output for numbers divisible by both 3 and 5.
